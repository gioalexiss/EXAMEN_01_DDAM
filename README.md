# ChatApp



## Acceso

```
Usuario:    admin
Contraseña: 123456
```

También se puede iniciar sesión con una cuenta creada desde la pantalla de registro, usando el usuario o el correo.

## Funcionalidades

- Validación de los campos en el login y en el registro.
- Cuentas guardadas en el teléfono con `SharedPreferences`.
- Búsqueda de usuarios por nombre o usuario.
- Envío de mensajes nuevos en el chat.
